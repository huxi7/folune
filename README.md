# Folune

AI 自动归档的备忘录软件。随手记录，让笔记逐步沉淀为可检索的文件树与知识画布。

## 开发入口

- [本地开发与部署](deploy/README.md)：Web、API 与 Chat 的运行方式和环境配置。
- [桌面端](desktop/README.md)：Electron 开发、打包与发布。
- [架构地图](CLAUDE.md)：技术栈、模块边界与源码导航。
- [文档索引](docs/README.md)：产品约束、设计规格和历史归档。

## 源码结构

| 目录 | 职责 |
| --- | --- |
| `app/` | React 用户端与共享设计系统 |
| `api/` | 业务接口与持久化边界 |
| `chat/` | AI 对话、审批与整理服务 |
| `desktop/` | 复用用户端的 Electron 桌面宿主 |
| `deploy/` | 容器构建与部署配置 |
| `scripts/` | 本地开发与运维命令 |
| `docs/` | 跨模块产品文档与历史归档 |

环境变量使用各模块的示例文件配置。真实凭据不进入 Git。
