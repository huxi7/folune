## 2. 空间导航

### 自适应 MiniMap（已裁决不做）

- 已有「适配视图」承担迷失恢复，真实使用没有证明需要第二套空间导航；MiniMap 不进入后续 Plan，也不再以“大画布也许会迷失”的假设保留待办。

### Focus Selection

- 在大画布中把当前选中对象平滑带回视口中心。
- 不改变节点坐标，不冒充自动布局；是否放入右上控制条由真实使用频率决定。

## 3. 直接操纵与效率

### 文件库拖入 Canvas

- 展开文件库后，可把已有笔记直接拖到 Canvas 指定位置。
- 这是复制投影到 Canvas，不是移动文件树节点；原目录位置不能改变。
- 已在 Canvas 的笔记执行定位与选中，不复制节点。
- 投放坐标、Panel 覆盖命中、拖拽预览与自动保存必须和文件树既有 DnD 语义隔离。

### 快捷键与命令补齐

- 在 MVP 已有可发现入口之上补充连接、聚焦、删除、预览、文字等高频加速器。
- 所有快捷键进入操作说明，并处理输入框、正文编辑、浏览器保留键和 reduced-motion 冲突。
- 全局 `⌘K` 的 Enter=打开语义不可改变；Canvas 添加继续使用显式 `＋` 或上下文关联入口。**（已成立：统一 Command Palette 于第 ③ 段交付，语义由 WorkspaceCommandPalette.test 锁定；本条从待办约束变为需要守住的既有事实。）**

## 4. 整理画布

「整理」是用户明确授权的一次批量空间变更，不是后台优化。

- 只能由用户主动触发，普通 AI 拓展永远不能借机搬动旧节点。
- 必须可预览或撤销；没有可靠 Undo 就不发布。
- 用户锁定/固定的节点不移动。
- 保持局部关系、主要方向和空间记忆，不把整张图完全洗牌。
- 后续可探索「只整理选中区域」，但不提前扩展 MVP 数据模型。
- 底层需要能够区分 AI 初始位置、用户手工位置和整理结果；具体协议由 Plan 2 基于届时代码决定。

## 5. Undo / Redo

- 覆盖移动、缩放自由文字、添加/移除节点、建立/删除边和整理布局等 Canvas 操作。
- 宪法第 6 节列出的阻塞级前置已经解除：普通节点/关系移除已有局部可撤销回执，批量移除原子提交；来源卡片事前确认，永久删除墓碑明确不可撤销。完整 Undo / Redo 仍是本节独立待办。
- 必须区分本地未提交历史与已持久化业务命令，避免表面撤销后刷新又复活。
- 不与原笔记编辑器的 CodeMirror 撤销栈混成一个栈。

## 6. 视觉与动效打磨

- 笔记卡片的纸张感、摘要渐隐、选择细描边、Hover 预览和操作行层级。**（全部已交付：纸张感与摘要渐隐来自共享 NotePaper，选中细描边与操作行/预览的透明度浮现已在 knowledge-canvas.css 落地。宪法第 6 节已把「不随缩放的浮动 Toolbar」推翻为「操作住在卡片里、跟卡片一起缩放」，因此本条不再有待办面。）**
- 推荐理由靠近目标节点的排版、多关系列表、关系 hover 与缩放阈值。
- AI 节点物化、连线生长、局部布局碰撞和大图缩放时的性能。
- 浮动边缘在多线重叠、近距离、节点换侧和自适应曲率下的可读性。
- 自由文字的缩放、换行、最小/最大尺寸和编辑/拖动手感。
- Canvas Controls、Panel 与 Preview Overlay 的 Quiet Editorial 同轴视觉。**（Preview Overlay 已由第 ① 段交付并与 Paper 共用同一 NotePaper；MiniMap 已裁决不做，Controls 与 Panel 的同轴收口在第 ② 段只做到顶层四块分区。）**
- 全部视觉调整继续复用现有 token 与 Design System，不创建 Canvas 专属第二套按钮、菜单或反馈系统。

- ~~大量节点与关系下的渲染、布局和自动保存批处理验收。~~ **已裁决不做：没有真实大画布性能问题前，不为与 MiniMap 同源的假定规模制造专项需求；出现可复现证据时再按具体瓶颈立项。**

## 8. 明确不默认进入 Phase 2

以下属于更远愿景，除非 MVP 真实使用产生强证据，否则 Plan 2 不得自动纳入：

- 全局 Canvas AI 对话和整图上下文推理；
- 多人光标、实时协作与离线同步；
- Canvas 内直接创建正式笔记或自由文字晋升；
- 自由画笔、形状、图片、Frame、Group、旋转和多页面；
- 后台自动持续探索与无人授权的布局变化。
- 订阅与 AI 用量计量。所有者已知当前订阅页仅有本地 UI 状态、`profiles` 无 plan/tier、四条 AI 路径不记录 token；本阶段明确不做。
