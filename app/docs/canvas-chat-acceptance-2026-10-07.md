# Canvas 只读问答验收

日期：2026-10-07。
实现范围：同一 Folune AI 的画布来源、只读问答与回复引用。

## 已实现

- 当前画布默认引用；笔记窗口支持 @画布。
- 来源可选整张画布或指定笔记。
- 清单搜索、逐项勾选、复制画布选中。
- Shift / Cmd / Ctrl 点击增减选择。
- 画布选择不自动改写问答来源。
- 发送前等待同步，按消息冻结范围和图版本。
- API 从持久消息恢复只读身份。
- Chat 仅提供来源、正文、文字、关系读取和引文核对工具。
- 每次正文读取最多 12,000 字符，本轮正文预算 120,000 字符。
- 图节点和关系每页最多 30 项，不限制画布节点数量。
- 回复引用按唯一笔记计数，关系/自由文字单列画布依据。
- 原位引用浮层展示短引文和支持的判断。
- 原文预览重新核验访问权与版本，定位引句所在段落。
- 引用定位只调整视口，不移动卡片或改变多选。
- 旧回复引用随消息保存，不随当前来源变化。
- 正式引用视图由会话注入，官网 Demo 保持无业务依赖。

## 登录态浏览器

使用本次新建的三篇验收笔记和独立画布。
两篇提供观察/写作材料，一篇作为排除项。

- 指定两篇提问，真实模型读取这两篇及已有关系。
- 已保存消息的工具记录未包含被排除的第三篇。
- 底部显示两篇笔记引用，并单列一项关系依据。
- 引用浮层显示真实原文片段。
- 查看原文显示只读 Paper，高亮引用段落，无编辑入口。
- Shift 点击增选和取消成功，问答范围保持不变。
- 刷新后恢复来源范围及旧回复引用。
- 整图自由文字问答返回原句，并显示画布依据。
- 直接提交改名命令返回 AI_CANVAS_READ_ONLY，标题与 revision 不变。
- 来源浮层在 520px 窗口内完整可用。
- 笔记窗口 @画布可打开同一来源清单。

## 供应商边界

DeepSeek 思考模式拒绝 required tool_choice。
生产流程不强制该选项，不关闭思考模式。
模型通过 cite_sources 显式登记引用，服务端逐字验证。
模型漏登记时，只补回答中实际出现的已读原文引句。
纯概括没有可验证引句且模型未登记时，不伪造引用。
逐字匹配证明出处，不保证结论逻辑成立；回答仍需用户核查。
