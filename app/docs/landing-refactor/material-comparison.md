## 两版材质

- 纸感统一：保留#F4F4F2背景、现有Hero颗粒波面与正文纸感；Header/公告补齐与页底同源的180px grain.png、3%浓度，控件位于纸纹之上。
- Laper白底：背景与不透明内容面采用#FCFCFD（Laper#FCFDFC的极轻蓝向投影），主产品展示和卡片白底；外侧导轨与章节空轨透出160px细噪点，内容面遮住底层颗粒；Hero用轻蓝渐变，避免原纸色shader混入白底。品牌图、正文内容、结构与交互保持。
- 原页噪点参数：SVG fractalNoise，baseFrequency=.88、numOctaves=4、stitchTiles=stitch、saturate=0、源矩形opacity=.62；宿主opacity=.16、multiply、contrast(1.35) brightness(.96)。不下载或引入远程运行包。
- Header开关只在DEV出现，sessionStorage仅记paper/white选择；生产默认纸感，白底不视为已定稿。切换无需导航，保持滚动、折叠状态和互动Demo实例；按钮固定宽度避免文字变化引发布局重排。
- 用户指定hover极轻偏蓝：index.css唯一亮色token --interactive-hover-light=#F4F5F6，APP/认证/营销标准控件与顶栏导航共读；暗色原有4%白混入规则不变。Laper#F4F6F5的通道偏色转蓝，不保留绿色或营销旧暖黄。

## 三种花纹

| 项目 | 原页定义及本地实现 |
| --- | --- |
| paper竖纹 | 28×49px；30°和150°的1px灰线，加90°的1px品牌线 |
| weave波浪 | 72×72px，三组原始Truchet path，描边1/1/.75px，non-scaling-stroke；复用项目已有TruchetPattern |
| index网格 | 22×22px的1px网格、11×11px的半径1px点；原页点心1px与网格线中心.5px偏离，本地统一中心.5px |
| 色彩 | 框线底色72%灰、品牌蓝32%、正文墨色28%点阵，整个纹样82% |
| 空间 | 固定CSS像素，不随轨宽缩放；左右轨间铺满整章，两端各16%渐隐；1280px以上显示 |

波浪三组路径逐字比对原页一致。网格点以(6,6)为tile内中心，背景位移(-5.5,-5.5)，产生.5+11n坐标；网格线中心为.5+22n，交叉点对应每隔一个点，误差为0。

## 动画

原页 LazyLandingSection 源码：rootMargin="-8% 0px -18% 0px"，once=true，进入后准备500ms；随后CSS再延迟500ms，1800ms cubic-bezier(.16,1,.3,1)以clip-path inset(0 0 100%)→inset(0)从上向下展开，saturate .8→1。SVG pathLength=1，stroke-dasharray=1、dashoffset 1→0，同一时序。

首页已按此实现，卸载清理准备计时器；两边同步，左侧结束提交完整态。保留首页一次显现缓存，切换材质不重播。目录仍沿既有按可见范围展开协议；减少动态即时完整显示。
