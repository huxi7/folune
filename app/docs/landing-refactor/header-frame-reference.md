## 边界

- Header与公告使用微蓝白底#FCFCFD（参考#FCFDFC的通道偏色投影）；首页主体继续使用既有纸色与Hero背景。整体观感因此保留Folune主题，不声称全页截图像素相同。
- 所有Blueprint骨架共读54/68/82%分层；正文模块边线消费82%；博客/价格的72%花纹从原始框线色混合，避免对82%重复相乘。暗色Footer保留白线覆盖。
- 手机Header保持48px并显示下载/打开；原生details折叠六项导航，展开不挤高页面，Escape恢复焦点，任何顶栏链接或按钮动作都会关闭它。Laper手机将登录换为菜单，本项目保留用户要求的两个动作。
- 节点不增加动画状态和测量状态，尺寸与中心由同一CSS坐标决定；图标、下载和认证继续复用现有组件。
