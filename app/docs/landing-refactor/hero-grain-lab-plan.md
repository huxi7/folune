> 依据：用户在本任务中的反馈、关联讨论《优化Landing Page》、当日正式 Hero 与六版 Lab 源码。当前未运行浏览器或测试；视觉判断为待实看验证的设计假设。

执行结果（2026-09-19）：四版及参数面板已写入 `/hero-lab.html` 的既有模块。01/04 使用 Paper ShaderMount 与局部颗粒 GLSL，02 使用 GrainGradient wave，03 使用 Dithering warp；A/B/D 原参数保留，E/F 从入口淘汰。支持自动本地保存、复制/载入配置、暂停定格对照和可选真实 APP 衔接。02 保留库原生纸粒尺寸，未伪造颗粒粗细旋钮；各版只展示实际生效的参数。当前默认值与实现限制见 `app/src/widgets/LandingHeroLab/REVIEW.md`。按用户既有要求未运行浏览器、测试或构建，不能把本轮视觉与性能视为已验收。下文保留计划原始决策，实际实现以本段与模块文档为准。

## 1. 目标与范围

围绕用户偏好的 A（GrainGradient）的颗粒、D（Dithering）的网点，以及 B（Warp）自然不规则的变化，深化四个颗粒 / 点阵候选。首眼读到标题，停留数秒能感到背景缓慢变化；既有纸色、墨蓝、导轨继续构成页面身份。

最新审美补充：用户喜欢 B 看起来无序、随机的形变，但正式页试放后觉得它过于光滑、完美，缺少纸感；喜欢 D 的网点材质，但对同心圆的规整感存疑。不能把这理解成否定 D，也不能归因于用户尚未欣赏到它：下一轮要区分材质、构图与尺寸三个变量。E（Waves）和 F（Beams）明确淘汰，不再作为活跃候选或推荐。主方向改为「自然不规则的形变 + 细颗粒 / 印刷网点 + 哑光纸感」。

本阶段只改 `app/src/widgets/LandingHeroLab/` 及其文档，继续使用 `/hero-lab.html`。不改正式 `LandingHero.tsx`、`landing.css`、共享组件、APP 展示、认证、正式路由或构建配置，不覆盖其他 Agent 的工作。A/B/D 原始参数保存为重点参照；E/F 从新版可见候选与比较入口移除，不为保留数量重新包装，既有 Git 历史保留追溯。新默认入口集中展示本轮四版。

冻结正式页当前的标题、副标题、按钮、公告及三栏定稿文案。副标题继承用户刚确认的浅灰层级，不再沿用旧 Lab 的深蓝灰文本，也不进一步调淡。保持标题水平居中，整组文案在 Hero 中垂直居中起步；加高时增加留白，不同比例放大字体、按钮或内间距。

## 2. 开始前先消除比较误差

当日源码显示：正式 Hero 的最小高度为 448px，旧 Lab 桌面最终覆盖值为 490px；正式标题 42.9px，旧 Lab 50px。Lab 还独立改变了 Header 高度、导航内容、公告、副标题和价值条字号。比较对象因此不只是背景。

执行时重新读取最新正式代码，用其 Header → 公告 → Hero 文案 / 按钮 → 三栏价值条的可见结构与生产样式建立统一 Demo 底板。复用已有 BrandMark、Button、BlueprintFrame、BlueprintDivider；通过 Demo 局部装配保持外观一致，不为复用而引入 Auth 或修改共享生产接口。所有新候选使用同一个底板，仅背景构图与参数不同；Header 不再作为每个候选独立改版。

不把旧 `hero-lab-research.md` 的三套 SVG 方案或 `REVIEW.md` 对 C 的历史推荐当成本轮结论。先前被用户否决的是那些具体成品；本轮以 A/B/D 的最新分项偏好和 E/F 的明确淘汰为准。

## 3. 四个候选：同一家族，构图不同

| 候选 | 视觉构图与动态 | 优先实现路径 | 需要避免 |
| --- | --- | --- | --- |
| 01 散墨流变 | 取 B 的不规则形变，用 A/D 启发的细墨粒表现深浅；画面像薄墨在纸上缓缓舒展，边缘软而略有参差 | 先核实既有 Warp 的场与材质控制能力；不足时以连续形变场驱动颗粒覆盖率的局部 shader 实现 | 光滑绸缎上叠一层均匀噪点；高光、折射、液态金属感 |
| 02 纸墨呼吸 | 延续 A：细纸粒承载宽阔、柔软的墨色明暗场，重心偏下或偏一侧，缓慢形变；轮廓比 01 更弱，强调纸面材质 | 现有 GrainGradient 调参，必要时调整局部构图遮罩 | 变成大块蓝色渐变；随机颗粒每帧跳变 |
| 03 游移网点 | 保留 D 的细网点，用非径向的连续场形成不等距、非闭合的疏密区域；整体缓慢形变，不出现清楚的波源 | 先检查现有 Dithering 的非径向形态；不足时用坐标扰动或非径向密度场，避免仅移动同心圆圆心 | 清晰同心圆、等间距波环、雷达感、像素雨、网点阈值闪烁 |
| 04 疏点薄雾 | 减少可辨认的波纹与轮廓，外围不均匀的点群缓慢聚散，中间自然留白，偏向空气感 | 确定种子的点场与连续密度场；优先复用现有运行生命周期 | 均匀星空、漂浮粒子、鼠标吸附、中央白色光斑 |

先完成 01/02 的成熟默认值，再做 03/04；不靠换名称、颜色或随机种子凑版本。四版必须在远观的明暗构图、近看的颗粒组织、时间上的变化方式中至少有一项明显区别。

设计起点优先 01「散墨流变」，02 作为纸感对照，03 单独回答「保留 D 的材质、去掉几何规整感」是否更合适。04 保留没有明显轮廓的更安静选择。最终排序留到实际画面比较之后；不预先宣称任何一版最好。

D 的原版可用同参数、不同高度作参照，但不占新候选名额。加高能让波面舒展，不能消除同心圆本身的径向对称与周期性；如大画幅下仍显得机械，应替换形态，而非持续放大或加噪声补救。

## 4. 材质与动态约束

- 底色沿用当前 `--landing-bg`，颗粒只在 Soft Ink 与纸色混合的低对比范围内取色，不增加青紫光、发光、光束或强高光。
- 区分两层尺度：细颗粒负责材质，大范围明暗负责运动。优先保持颗粒采样稳定，让连续场缓慢变化；若移动颗粒坐标，保证连续移动，不逐帧重新随机生成。
- B 的改造先处理材质：压低过亮区域与光滑明暗带，以颗粒的覆盖率 / 浓淡表现墨色深浅，让轮廓有轻微自然起伏。整幅叠一层噪点不能替代这一步，否则只会得到「蒙了灰的绸缎」。纸感主要来自哑光、不均匀着墨与细微粗糙，不靠仿旧污渍。
- “随机”是视觉上的难以预测，不是每帧抽新随机数。采用连续、可复现的缓慢变化，避免骤变和短周期往返；细网点可以有秩序，宏观疏密与走势应自然不规则。页面导轨已经承担秩序，无须背景再重复一个鲜明几何中心。
- “慢”不等于不可见。正常播放时，停留约 3–5 秒应能察觉外围构图在改变；连续阅读约 30 秒不应被周期性闪烁、明显波峰或突然出现的暗块打断。不能靠 10 倍速证明动画存在。
- 首帧即是成熟构图，不能从空白等十几秒才出现；默认种子和起始相位固定，便于复现。
- 中心稀疏区覆盖标题、副标题和 CTA 整组内容，移动端随换行调整。优先在场本身衰减密度 / 对比，必要时加柔和纸色遮罩，避免盖出可辨认的白色椭圆或卡片。
- 大波面尺度与颗粒尺寸分开控制。颗粒按可见 CSS 像素理解，不能随 Hero 高度变大就被一起拉粗；处理高 DPI、缩放与抗锯齿，观察细网点的摩尔纹和时间闪烁。
- 不增加鼠标追光、视差、标题漂浮或滚动劫持。所有候选的文字与骨架静止。

## 5. Hero 高度与页面节奏

高度是独立比较维度，不能每个 Shader 自动换一种高度。四版默认使用同一档，切换候选保留用户选择的高度。

起始提供三个语义档位，并允许连续微调：

| 档位 | 试排起点，不是已验证定稿 | 目的 |
| --- | --- | --- |
| 紧凑 | 约 60svh | 看产品是否更快进入视野 |
| 舒展，默认 | 约 68svh | 先增加留白，保持首屏的内容节奏 |
| 沉浸 | 约 76svh | 比较更大面积是否确实改善材质表现 |

桌面先在约 440–800px 范围试排。不要机械应用 `clamp(600px,72svh,760px)`：在 768px 高的视口，600px Hero 加当前 57px Header、37px 公告和约 98px 三栏已经超过一屏，APP 顶部会完全消失；实际三栏高度还会随宽度变化。

最终高度优先参考整段预算：可见视口 − Header − 公告 − 三栏实际高度 − 少量 APP 露出。常见桌面以能完整看到三栏并露出约 48–96px APP 起始部分为比较目标，短屏优先收缩 Hero 留白；同时保留文字与按钮的内容最小高度，不强制塞满一屏。沉浸档允许 APP 落到下一屏，用来比较这一取舍。

高度使用预览实际视口，不把控制面板占用空间误算成产品高度。手机采用内容驱动的 min-height 与独立上下留白，不照搬桌面的 600/620px 下限，也不要求纵排三栏全挤在首屏。

默认演示仍完整呈现 Header → Hero → 三栏。另提供可选“查看 APP 衔接”，在其下只读装配现有 `LandingEditor`，保持当前展示样式与独立 Demo 行为；不修改 APP 展示本身。以此观察 Hero 动态颗粒 → 干净三栏 → APP 现有点阵后景的节奏，不画一个假的产品占位框。

## 6. 两侧导轨与下方衔接

保留 1120px 主轨和现有外轨坐标。Hero 背景作为一个连续场覆盖中央与侧边区域，侧边降低对比、减少细节；不新增左右两个独立画布，不各自设计一套动画。

导轨继续静止，主角始终是中央文案。第一轮不叠加新刻度、数字、工程注释、十字光标或第三套纹理；已有细线加颗粒场足够表达层次，待画面确实需要时才保留少量辅助标记。

进入三栏前逐渐减弱背景，三栏保持清楚、安静。后续 APP 已有细点阵背景，Hero 应通过大尺度场与更低对比区别开，而不是把同一纹理平铺到整页。

## 7. Lab 的交互与参数

以完整实际宽度的首屏为主。控制面板可收起，默认不占用预览布局宽度；打开时可以覆盖右侧操作区，收起即恢复无干扰观察。窄屏用可收起抽屉，不让面板把 Hero 挤成手机宽度。

基础控制保持少量、直观：

1. 方案选择与 Hero 高度档位 / 滑杆。
2. 背景浓淡。
3. 颗粒粗细。
4. 图案尺度：大范围明暗结构的大小。
5. 动态速度。
6. 中央留白。

高级项按方案实际能力展开：点阵密度、形变程度、位置 / 重心、方向。其中「形态自然度」可控制连续场的扰动程度，与颗粒粗细和动态速度分开；不得用每帧随机刷新实现。不要给不支持的效果塞无效旋钮，不把“密度”和“透明度”做成两条实际相同的控制。颜色锁在品牌范围，不做任意颜色编辑器。

每一版先交付作者调好的默认参数，再允许用户微调。UI 用中文说明参数影响；跨不同 shader 的 speed=0.15 没有统一视觉含义，不照抄讨论中的假定数值。控制上下限也按各方案可用范围确定，初始重点覆盖默认值附近约 ±30% 的调节空间。

必须支持：暂停 / 恢复、恢复当前方案默认值、保留各方案调节值、固定一个“对照方案”、复制当前配置与重新载入配置。配置包含版本、方案 ID、参数、种子和高度策略；暂停对比时保留相位，保证截图可复现。仅本地 Lab 保存，无账号、后端或云同步。

对照采用同一完整视口的一键切换，并可锁定高度与时间；不默认同时播放四个缩小画面。控制面板能显示默认值与已修改状态，不在产品画面叠加 Shader 名字、FPS 或技术标签。导出配置能被后续实现直接读取，避免用户调好后人工抄错。

## 8. 实现边界与性能

已有 `@paper-design/shaders-react@0.0.80` 的实际类型和源码是库能力的依据；执行时仅定向阅读与四个方向有关的组件资料，不重做泛组件库海选。

先核实已有组件是否能实现所需材质与形态，02 优先基于 GrainGradient，01 从 Warp 的形变思路切入，03 从 Dithering 的非径向形态切入。只有出现具体限制，例如光滑底层无法转成颗粒着墨、点径与波面无法分离、中心留白构图无法控制或阈值闪烁难以消除，才为相关候选写局部 GLSL。记录替换原因；“自己写一定更高级”不是理由。自写 Shader 同样必须真实连续运行，不能回到静态 SVG 或 CSS 示意画。

保持装配、参数、背景算法、运行生命周期分工清楚；可按需要拆 `presets`、`Controls` 和背景组件，不做通用 Shader 编辑器，不新增 Three.js/R3F 等重型引擎。

复用现有 `useAmbientMotion` 的暂停、减少动态、后台、离屏边界。一次只运行一个 Hero 候选，参数变化不重建 WebGL context、不重置时钟，逐帧更新不经 React state。相邻 APP 背景按其现有可见性规则工作，不能把“一个 Hero”误报成全页只用一个画布。

现有 140 万像素上限作为起点，不把提高 DPR 当作提高清晰度的唯一手段；低 DPR 下仍需保持点阵稳定。支持上下文丢失与不支持 WebGL 的明确状态，备用画面使用同色静态代表帧或纸面。系统减少动态时直接显示有完成度的静帧，不为了证明会动绕过用户偏好。

冻结最终方案时再讨论正式加载路径、生产增量与长期维护；不能用四版 Lab 的总包体积代表单版最终成本。

## 9. 执行顺序与交付

1. 确认最新生产视觉、已定稿文案及并行 Agent 的修改边界；保存原 A/B/D 参数参照，移除 E/F 的可见候选入口，建立一致底板。
2. 实现高度控制及可收起面板，先精修 01/02，再完成有真实差异的 03/04。每版都先有默认成品，不把调参工作转嫁给用户。
3. 完成同视口对照、配置保存 / 导入 / 导出，以及可选 APP 衔接视图。
4. 回环更新本模块 L3/L2 和本计划对应的执行状态；此前历史推荐保持明确的历史身份。上层地图存在“三版 / 六版”描述不一致，执行时仅在确认无并行冲突后做最小文档同步，不改生产源码。
5. 交付可打开的 Lab、四套默认参数、简短差异说明和有证据边界的推荐。选定后进入另一个明确的正式接入阶段，本计划不自动执行接入。

视觉验收提纲：同尺寸同文案切换；实际播放看 3–5 秒变化和 30 秒阅读舒适度；暂停 / 恢复不跳相位；改高度不放大颗粒；1440×900、1366×768 和手机尺寸看构图与溢出；观察三栏及 APP 衔接；参数导出再导入能重现选择。

用户此前明确要求停止测试并自行看效果，这一偏好仍有效。本计划列出判断标准，不授权自动恢复浏览器验收、截图、性能测试或完整测试套件。执行时若没有新的验收授权，直接交付页面供用户观察，并明确哪些效果尚未实际验证；不拿历史检查冒充新方案证据。
