采集说明：Ego Lite 首次截图成功，之后截图接口持续超时；Codex 内置浏览器的整页拼接也受到页面平滑滚动与像素缩放影响。正式证据使用内置 Chromium 的 1672 × 1000 原始视口截图，以瞬时滚动 + 两帧绘制等待采集，并按实际 scrollY 拼接；从后续片段裁去已经覆盖的内容与 sticky Header，保留首屏 Header。页面内容没有为了截图改成图片。临时采集状态不写入产品代码。

仍有差异：原稿编辑器的细小工具/状态图标与线程状态没有逐项复刻为 Zed 的可工作环境；基线只提供其三栏结构和可见内容。字体栅格化、细线与导入稿亚像素尺寸存在平台差异。参考的滚动 Logo、视频播放与动态演示未提供确定交互稿，本阶段保留静态状态。移动端为自主流式适配，最终移动验收在第二阶段完成。

检查：TypeScript、oxlint、515 项 APP 测试（0 失败）与 Vite 生产构建通过。构建仍提示已有 Mastra 浏览器 externalization 与大 chunk，不属于本任务新增的产品能力或性能承诺。
